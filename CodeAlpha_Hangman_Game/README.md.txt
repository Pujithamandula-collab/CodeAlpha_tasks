# CodeAlpha Hangman Game

## Project Description

A simple text-based Hangman game developed as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time. The player is allowed a maximum of 6 incorrect guesses.

## Features

- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Displays the progress of the word
- Keeps track of guessed letters
- Allows a maximum of 6 incorrect guesses
- Displays the correct word when the player loses

## Technologies Used

- Python
- Random module
- Strings
- Lists
- Loops
- Conditional statements
- User input/output

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project in VS Code or any Python-supported editor.
3. Open the file `CodeAlpha_Hangman_Game.py`.
4. Run the program.
5. Enter one letter at a time when prompted.
